# An absolute-address temporal handoff control

Register the control after the initial spatial and short-PC studies, before reading any results of these new predictors. The previous spatial study includes an offline frequency table for physical lines. This control tests whether updating exact physical successors on each observed arrival can learn recurring nonlocal handoffs that a frozen table missed. Use all 16 discovery traces in each of the two short windows, and all seven existing Google discovery objects in the deep window. The reserved families remain unopened.

At every per-core Stride LLC demand ingress, use a dedicated conventional table to offer at most one absolute physical cache line. A stored successor is already observed on this core in this placement. Reset every table at each ROI. Inspect all eligible ingresses, including successful hits and silent streams. Compare keys of current PC, current physical line, and (PC, line). Each key stores its last observed successor, requires an exact key-tag match, and may issue after one training occurrence. Hash deterministically to 256 direct-mapped entries. For line alone include an unlimited dictionary as a capacity diagnostic. Compare to same-page next-line. Budget one candidate per trigger per method; do not merge their proposals. These are reference predictions without extra inference delay, queue checks or service intervention.

Run independent horizon-one and horizon-four tasks. For horizon h, capture the offered address from the prefix available at i; after this decision associate the trigger h events ago with the current physical line. No labels about subsequent hits, misses or service enter table update or inference. Exclude self-prefetches. Score only the chronological last 20% of each trajectory, while online state keeps observing prefix arrivals including the evaluation suffix. For the outcome at i+h to earn prefetch credit, the target must be distinct from the cue, and no intervening same-line demand may use it sooner. Count all eligible positions and offers, including wrong/short-lead ones.

Use the median dispatch-to-fill of demand services completed before the end of the initial 60% of this same materialized stream as a lead reference. If no such service exists, use the study's fixed 128-cycle reference and label fallback. This proxy cannot establish native timeliness. Report aligned original NoPF misses and the subset actually missing at the LLC for Stride, multi-delta and SPP on the same dynamic operand. Separate previously unseen lines, previously unseen target pages, targets outside the last three distinct pages including the current page, displacement over 512 lines and combinations. Break outcome counts down by whether the demand PC ever had a direct timely first-use in this Stride ROI (offline label). IDs include core-local original instruction and operand. Hold state and deadlines within each original run clock. Run zero-ingress examples as explicit zero-support cases. A result for the strongest conditioned subset requires a direct earlier address, a legal observed target line, sufficient reference lead, a real NoPF miss and actual tag misses under all three native controls. It still needs actual intervention to establish incremental performance relevance.
