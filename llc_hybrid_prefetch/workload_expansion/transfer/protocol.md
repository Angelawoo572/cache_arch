# A second interval for every discovery recording

Register before opening the native screening outcomes. Apply the same machine, four native policies, deterministic physical page allocation, one core and 250,000 retired instructions to both intervals. Initial window A warms on the first 100,000 instructions and measures 100,001–350,000. For B, skip the first 450,000 while registering pages, warm on the next 100,000 and measure 550,001–800,000. Each B run starts from reset and has its own timing, caches and warmup. The intervals do not share demand operands. This is a temporal replication on the named discovery recordings. Entire reserved workload families stay closed.

**Question.** Does an additional, earlier cue distinguish two useful physical addresses in a new interval that one fixed local context cannot distinguish? Do the native prefetchers already cover both futures? We do not assume a loop, a recurrent network, or a privileged length/shape for the output.

- Fit compact descriptive rules using the first 60% of A's Stride ingresses only. No development or B measurements may choose capacity, vocabulary, lead threshold, history or horizon. For additional validation score only B, with no rule updates. The adjacent first-window 20% development and 20% test are reserved for the primary study. Use horizons 1, 4 and 16 future LLC ingresses. Reset online history at the start of each measured window, count both real successes and false proposals across all eligible anchors, and tabulate near and far horizons separately. No leaf may use a future PC, region, outcome or timing as input.
- Index a base rule by current PC, exact within-page line offset and the two latest same-PC line deltas, clipped separately to ±64, with distinct cold tokens. This stricter local match stresses the cross-context explanation. Contrast current local context against the previous three global PCs (in order or sorted). An order-only test requires the same three PC identities including multiplicity in different orders. Also compare without PC identities, using the equality relationships among those sites and the current site; by construction those keys alone do not identify a program. A top-frequency action and same-page next-line are controls. Each table retains the 256 most frequent training contexts with support ≥3; ranks and ties are deterministic. It keeps a single output per context, with no uncharged fallback to a second table. Publish support, abstentions and actual offered requests for each rule. These are tests of what the history says at fixed capacity; they charge no inference latency.
- The action is a signed physical line displacement of magnitude 1–512. Same-page prediction is legal; a cross-page action additionally needs the destination physical page to have been observed by this core by that trigger. No virtual page adjacency or unlimited physical reach is assumed. Report targets outside this vocabulary. The seen-page set is an offline ceiling on addressability, not an implemented hardware structure. Exclude intervening references to the target when scoring first demand use. The decision has useful lead in this diagnostic if the demand ingress follows the trigger by at least the median completed baseline demand dispatch-to-fill service estimated in the A training time range. Actual useful arrival still requires a native replay.
- Align original NoPF misses with each policy using instruction ordinal and operand. A target is a gap in the four-arm comparison when it was an original LLC miss and all three conventional policies actually missed/merged on it, with no timely fill in any. Report separate counts for additional correct predictions over the local rule, foregone correct predictions, and original target head-wait exposure. Never add per-load waits as independent saved cycles. All miss/hit, future address and exposure labels are retrospective. Distinguish never-proposed, late or indirect coverage where logs permit.
- Stronger positive evidence requires the same exact local key in A and B, two distinct historical cue values, and two distinct trained actions. Both branches must be correctly predicted in B with a legal address, no intervening use and the training-derived lead. Keep B examples and report when support for this strict test is zero. Measure how much survives existing conventional coverage. This is a lower bound under these probes, and successful contexts are selected after scoring; other eligible anchors remain in full-stream denominators.
- Workload-level cycles and pressure are native from A and B. Report changes in which baseline wins and whether lessons transfer between disjoint intervals. The independent family holdout is for a later confirmatory experiment; no performance result is attributed to it here.
