# Marginal value of one earlier address

One BFS-3 example in the structural-rule run named a previously demand-unseen physical line 618 instructions before its first data use. All three conventional predictors later identified the target and recorded a late merge. To separate the value of this event from the thousands of other changed decisions, repeat each original 50M/200M Stride and SPP execution with one override. At measured demand anchor 100,100,888, operand 0, submit current physical line +3 through the shared issuer. Every other proposal comes from the normal predictor observing its own changed execution. The workload was selected retrospectively, making the choice of anchor a diagnostic intervention. An online predictor cannot use this dynamic ID. The one-request performance difference includes the displaced offer and any subsequent feedback, queuing and cache effects.

From the repository root run `python3 -B llc_hybrid_prefetch/full_workload/single_address/replay.py` once the BFS-3 baselines have completed. The output reports each run's candidate lifecycle and exact target's head wait as well as completion time and collateral first-use changes.

## Observed marginal effect

| Reference | Original → replacement physical line | Target late → timely | Target head wait before / after | Whole-ROI cycles saved | Other and target timely outcomes gained / lost |
|---|---|---|---:|---:|---:|
| Stride | 3,500,604 → 3,500,606 | Yes | 0 / 0 | +20,856 (0.0030%) | 8,709 / 8,661 |
| SPP | 3,500,604 → 3,500,606 | Yes | 0 / 0 | −63,240 (−0.0099%) | 21,619 / 23,293 |

The original proposal at the anchor was itself accepted and timely for a different line. Earlier service for the chosen load improved its classification under both policies. The initial quarter's paired demand masks and completion cycles are identical. After the single replacement, the two runs evolved different request timing and subsequent cache/predictor behavior. The direction of the final fixed-work difference depends on which predictor receives the override. Assigning either whole-run difference to the latency of the chosen load would misstate this experiment. [Measured results](results.csv)
