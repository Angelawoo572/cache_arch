# Physical page and service test on CactuBSSN

The R1-trained address ranking had already been evaluated offline on R2 when this follow-up was designed. Its weights, vocabulary, grant schedule and thresholds are frozen. This replay is a post-hoc mechanism test on the observed case. An independent third recording would be necessary for a fresh confirmation.

1. Compare no prefetch, original Stride, Stride plus a fixed physical +128-line target, and Stride plus the frozen R1 ranking on all eligible R2 ingress events. Grant at most one extra *choice* on an eligible trigger and retain a total issue degree of one. A valid extra choice replaces the native choice. Use the same shared tag, MSHR, RQ, WQ and PQ checks, shared replacement, memory timing and 5M retired instructions. Track agreement and first-use attribution even for same-page choices.
2. Permit a cross-page target only on the current core's previously observed physical pages in this address space. Compare an ideal record of seen pages with an additional 16-entry fully associative recent-page admission gate; retain the native candidate if the gate drops the auxiliary choice. This extra gate bounds issuer confirmation; the generator still uses its original reference structures.
3. Repeat with the same virtual instructions, the same 64-page allocation chunks and a bit-reversal permutation of the six frame-index bits within each chunk. Measure both NoPF and Stride under each mapping. Do not use virtual page adjacency. The changed mapping can also alter DRAM and cache mapping, so use each layout's own baseline.
4. Record traffic, both coverage and actual cycles. Compare the exact example picked in the offline study using core, instruction, operand and matching virtual address. For each original-layout live auxiliary choice, count whether the reference stream contains the same trigger ID, physical base and target. The resulting common-choice count uses all live auxiliary choices as its denominator. The general mechanism requires an explicit legal physical-page/region handle with ownership and invalidation. The trace machine has no dynamic remapping/context switches and cannot establish such support for a general operating system.
