# Prospective address-information probe

The unit is a demand admitted to the LLC in a measured Stride execution. Keep the full arrival stream in chronological order. Select one diagnostic anchor per fixed-size block at a reproducible pseudorandom offset, targeting 30,000 anchors per recording. Each anchor can predict physical addresses independently. Sample membership never uses request outcomes. The final 32 arrivals have incomplete labels and are censored.

Split by arrival index at 60% and 80%. The first partition supplies the training targets, action vocabulary, preprocessing and fitted trees. Ensemble capacity and scoring rules are fixed across runs. The middle partition reports development scores. The last partition supplies the chronological test. Purge anchors whose future targets would cross a partition boundary. Histories can observe earlier partitions. Score horizons 1, 8 and 32 separately. The dataset itself supports more horizons. For cross-recording tests, freeze the source training vocabulary and fitted trees, and score the destination's last partition. Record when two views share a source or an executable. Report independent inputs only where published provenance identifies the input.

Two independent target encodings are tested. The first learns signed physical-line displacements from the current line. The second learns offsets on a causal list of up to eight recently observed physical pages. The eligible set includes the current page and at most seven others from the previous 64 arrivals. At each horizon, take the 64 most common training actions for each encoding and reserve one probability class for every other outcome. An abstention cannot earn exact-address credit. Report log loss on this finite alphabet, its coverage, and separately exact physical-line correctness, conservative legal reach and lead time. When comparing history scopes, hold the fitted target vocabulary, samples and horizon fixed. Log losses on different vocabularies have different meanings.

Use a fixed-capacity probabilistic tree ensemble as an offline diagnostic, with matched settings across feature scopes. Fit a smoothed training-frequency prior as the null. Compare current PC and offset, same-PC history, region history, ordered global histories of 4, 8, 16, 32 and 64 arrivals, history without absolute PC identity, and timing increments. Permute the order of earlier tokens within each anchor for an order control. Report both the gained address accuracy and the change in probability assigned to the true future. Stratify results by train PC/page exposure and by the target's previous visibility in the destination stream.

Physical line arithmetic must resolve to a valid line on the current or a recently observed page for the conservative legal metric. Report address hits on unseen lines and the space between the cue and the target's demand, measured in that execution. The 130-cycle lead bin uses the earlier study's reference and is an opportunity screen. Native request service, marginal IPC and hardware cost require replay.

The extended matrix uses the seven fixed feature scopes listed in `suite.py`. Scope includes phase transfer, distinct MCF/BFS recordings, held-out SPEC/GAP executables, and GCC/CC placement checks. Named input transfer uses the Stanford BFS training graph and the separately acquired Google graph with the same binary. The MCF placement diagnostic uses the same source instructions with a nonuniform physical page mapping.

The other-PC ablation preserves all event positions and same-PC indicators while masking older events from other producers. The region-only and local-plus-region controls retain histories grouped by a 256 KiB physical region. A separate six-byte pressure probe uses measured LLC queues and memory-controller occupancy. A core-side diagnostic uses the trigger instruction's register fields, distances to earlier definitions and branch outcomes beyond the 256-entry ROB. Transporting these fields would require a core-to-LLC feedback path. No future fields enter these features. Conditional log loss on in-vocabulary targets and a mandatory one-address-per-anchor score audit the role of the out-of-vocabulary class and of abstention. These scoring diagnostics leave the predictors unchanged.


## Isolated issue replay

A separate one-off replay freezes the Soplex-trained global-32, horizon-eight displacement probe. Use the first sampled eligible BFS-3 cue in [80%, 85%) of baseline admissions. Use the first eligible cue in [90%, 95%) only if the same-PC model abstains or proposes a different line. Eligibility requires a concrete, nonzero displacement to a line on the cue's own physical page. The selector reads no held-out target fields or outcome masks. An empty window yields no offer and receives no replacement. Test-set aggregate results were already known when these replay rules were defined, so the replay measures the selected decision in these previously studied workloads. The multi-donor sensitivity test fixes three training programs before reading the expansion probe scores. Sample 12,000 evenly spaced training anchors each from BFS-3, MCF17-472B start and Soplex-92B. Fit one shared displacement vocabulary, a PC dictionary and a horizon-eight tree ensemble on the pooled 36,000 anchors. Compare same-PC, local-plus-region, global-32 and global-32 with absolute PC IDs removed. Apply the frozen fit to the eleven expansion recordings. Report all eligible cues, unseen training PCs and new target lines on known pages. This is a separate diagnostic from the single-donor transfer matrix.


For the eleven external rich captures, freeze the original BFS-3 horizon-eight model and apply the same timing context with three predetermined feature sets. The first sees the age of past demand events. The second also sees earlier LLC tag hits and their ages. The third adds prior Stride stage, reason and age. Callback categories are normalized by stable names across simulations. Each run requires native parity validation and a full count plus sampled key/PC/line/cycle match to the scorer's input stream. The same donor alphabet is used in all three fits.


The separate service/AI diagnostic applies the existing BFS-only H8 displacement probes to the two [domain recordings](../domains/sources.csv). The source data, three feature scopes, vocabulary and decision rules stay frozen. Compare same-PC, local-plus-region and global-32. Join each target to all four native policy outcomes. Both recordings had prior short screening. They extend domains in this experiment and remain separate from the eleven-recording external matrix and the previously reserved test traces.
