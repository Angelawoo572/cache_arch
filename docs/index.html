Research method

One comparison boundary, end to end.

Conventional-prefetcher outputs supervise the model during training, but are never neural runtime features, gates, candidates, or request budgets. The replay—not label accuracy alone—is the final evaluation boundary.

01

Capture

Record the chronological callback fields visible at the selected prefetcher’s source interface.

02

Supervise

Use conventional actions as training labels while keeping private normal-prefetcher state out of neural inputs.

03

Infer

Let the recurrent student produce its own request count, address deltas, and track-specific decisions.

04

Replay

Send both action lists through the same keyed ChampSim transport and measure cache-level outcomes and IPC.
