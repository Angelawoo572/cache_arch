\section*{Why v24 replaces the v23 decoder}
The v23 prior correction reduced requests but still produced 1.33--1.38 times
the normal Stride request count, while all five IPC values remained effectively
equal to normal Stride.  v24 therefore retrains the action-list likelihood
rather than applying another decode-only correction.

For callback context $h_t$, teacher count $K_t$, and teacher targets $a_{t,r}$,
the model minimizes
\[
 -\log P(K_t\mid h_t)
 -\sum_{r=0}^{K_t-1}\log P(a_{t,r}\mid h_t,r).
\]
$K$ is an unweighted categorical class from zero through the complete original
TRAIN maximum.  $K=0$ is the implicit hurdle.  Only real teacher ranks receive
delta loss.  There is no weighted hurdle, log-count regression, STOP padding,
class reweighting, decode prior correction, threshold, or action feedback.

\section*{Fair-input and model contract}
\begin{tabularx}{\linewidth}{@{}lX@{}}
\toprule
Item & Contract \\
\midrule
Runtime input & Lossless raw PC64 plus current cache-line58 only. \\
History & One shared-weight LSTM with hidden/cell state routed by exact observed PC. \\
Teacher actions & Labels, comparator, and diagnosis only; never model input. \\
Output & Categorical count followed by exactly $K$ current-demand-relative rank deltas; fill is always FILL\_L2, so no fill head is created. \\
Excluded & Handcrafted stride/reuse features, normal candidates/private state, request budget, page rules, thresholds, and action feedback. \\
Input reuse & The v23 input directory and archive are reused byte-for-byte. \\
\bottomrule
\end{tabularx}

The delta vocabulary is learned from FIT-TRAIN and includes a continuous
signed-log OTHER escape.  All five hidden sizes 8, 16, 32, 64, and 128 are
trained from scratch.

\section*{Checkpoint selection}
The original TRAIN sequence is split chronologically: a suffix equal in length
to the original GUARD phase is held out.  Checkpoint selection minimizes
natural action-list NLL on that blocked suffix, with earlier epoch as the only
tie-break.  The original GUARD remains a phase-shift audit and EVAL never
selects a checkpoint.

For count classes $K$, delta classes $C$, and hidden size $H$, the realized
parameter count is
\[
N=8H^2+(122+4+K+C+11)H+K+C+1.
\]

\section*{Required evidence}
Each point reports IPC, L2 miss rate, raw and selected accuracy, coverage,
timeliness, request pressure, fill level, count confusion and MAE,
trigger/target precision and recall, request ratio, count/delta entropy, and
action-list identity.  Denominator-zero ratios are N/A; no composite score is
used.

Oracle-count plus NN-action and NN-count plus oracle-action are diagnosis-only
and are never replayed.  PASS proves fairness and accounting integrity, not a
performance win.
