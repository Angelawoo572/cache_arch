\section*{What v23 measured}
v23 reused the byte-identical v22 checkpoints and changed only the decoding
rule to subtract the logarithm of the TRAIN class weight.  It therefore tested
post-hoc prior correction, not a new recurrent architecture or more capacity.

The directly supported failure is the mismatch among weighted training,
finite-model calibration, decode-only prior correction, and checkpoint
selection.  In addition, an exact-PC-only cell receives no intervening
other-PC callbacks, so it cannot represent chronological tracker interference
or staleness.  That is a structural blind spot, not proof that PC/line input is
insufficient.

\section*{Unchanged input and new recurrent core}
The runtime input remains exactly lossless PC64 plus current line58.  Normal
Stride actions are labels and an offline comparator only; candidates, tracker
state, confidence, degree, request rate, queue state, future events, and action
outcomes are excluded.

For each total hidden width $H\in\{8,16,32,64,128\}$, v25 splits $H$ evenly
between a global chronological LSTM and an exact-PC local LSTM, then applies a
learned fusion.  Thus the model sees both callback interleaving and same-PC
history without copying the normal 64-entry tracker.

\section*{Natural hurdle/list likelihood}
For context $h_t$, positive count $K_t$, and ordered targets $a_{t,r}$, v25
minimizes the complete per-callback negative log likelihood
\[
-\log P(Z_t\mid h_t)
-\mathbf{1}[Z_t=\mathrm{POS}]\log P(K_t\mid h_t)
-\sum_{r<K_t}\log P(a_{t,r}\mid h_t,r).
\]
The hurdle and positive categorical count are unweighted.  Every real teacher
rank supervises all 58 modular delta bits; there is no token vocabulary or
escape head.  The bit-head weight starts at zero and its bias is the
add-one-smoothed per-bit marginal logit of FIT for selection and complete TRAIN
for final retraining.  This is natural-prior initialization, not reweighting.
Ordered decoding uses exact k-best Bernoulli enumeration under a deterministic
uniqueness feasibility mask.  It never mutates a target, uses a threshold/page
rule/normal budget, or feeds an action back into the NN.

For $K$ realized positive-count classes, the exact
parameter count is
\[
N=5H^2+(201+K)H+K+60.
\]

\section*{Selection and required evidence}
The first 80\% of original TRAIN is FIT and the final 20\% is chronological
validation.  FIT alone defines selection support.  Minimum complete NLL
selects the epoch; an exact tie selects the earlier epoch.  The seed is reset
and a fresh model is then retrained on complete TRAIN for exactly that many
epochs with complete-TRAIN support.  Original GUARD is a phase-shift audit;
EVAL is decoded once.

The final evidence keeps IPC, miss rate, request ratio, hurdle/count confusion,
trigger precision/recall, target precision/recall, per-bit entropy,
uniqueness, entropy, timeliness, and action-list hashes separate.  Oracle
decompositions are diagnosis-only and are not replayed.  PASS proves fairness
and accounting, not a performance win.
