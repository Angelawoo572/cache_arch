\section*{Evidence-driven redesign}
v23 made 93.40\% of padded rank labels STOP although 58.05\% of EVAL callbacks
had actions.  Its five models emitted 0, 1, 991, 2,325, and 5,096 requests
versus 804,086 teacher requests, and all stayed at no-prefetch IPC 0.35321.
Normal SPP reached IPC 0.35390 with those 804,086 requests, while the non-neural
modal $(+3,\mathrm{LLC})$ control reached IPC 0.35424.  Thus the replay contains
useful spatial actions; v23 did not learn to express them.
The abandoned v24 token vocabulary fixed padding but left its OTHER payload
heads without TRAIN labels because every TRAIN pair was an exact token.  It also
did not combine payload probability with token probability during decode.

\section*{Unchanged information boundary}
The external input remains one callback-kind bit and one lossless 58-bit demand
or evicted line in recorded source chronology.  PC, SPP private state,
candidates, outcomes, thresholds, and request rate are excluded.  All five
hidden sizes use one global chronological one-layer LSTM.

\section*{Complete real-rank likelihood}
For callback context $h_t$, count $K_t$, fill $f_{t,r}$, and modular delta bits
$d_{t,r,b}$, v25 minimizes
\[
 -\log p(K_t\mid h_t)
 -\sum_{r<K_t}\log p(f_{t,r}\mid h_t,r)
 -\sum_{r<K_t}\sum_{b=0}^{57}
   \log p(d_{t,r,b}\mid h_t,r,f_{t,r}).
\]
The same per-callback sum is used for TRAIN optimization and GUARD checkpoint
selection.  Both fill-specific bit heads require actual TRAIN actions.  Fill
and bit biases use add-one-smoothed TRAIN marginals only for initialization;
loss remains unweighted.  There is no STOP padding, action vocabulary, OTHER
token, class weighting, prior correction, float delta, clipping, or rounding.

\section*{Exact feasible decode}
Count argmax chooses $K$.  At each source-ordered rank and for each fill, the
modal 58-bit assignment has stable log probability
\[
 -\sum_b\log(1+e^{-|z_b|}),
\]
and flipping bit $b$ reduces it by $|z_b|$.  Exact k-best subset enumeration
therefore finds the highest-probability payload not already used.  L2 and LLC
candidates are compared by fill log probability plus payload log probability.
The target mask crosses fill levels; it never changes a target or reduces $K$.
Previous actions are feasibility state only, never neural input.  No same-page
rule or normal-prefetcher template is imposed.

For count classes $K$ and hidden size $H$, parameters are
\[
9H^2+(191+K)H+K+118.
\]
EVAL is loaded after GUARD selection and decoded once.  Oracle decompositions
remain non-replayed diagnostics, and the modal-LLC control is non-neural.  IPC,
miss, request, usefulness, timeliness, fill, count, target, entropy, and mask
evidence must be reported separately after all five replay points complete.
