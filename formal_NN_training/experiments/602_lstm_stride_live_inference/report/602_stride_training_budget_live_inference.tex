\section{Question and deployment contract}
This study asks, separately for h16 and h8, for the smallest offline training
prefix that preserves system performance when frozen inference executes in
the live ChampSim L2 callback. “Online” denotes callback placement only.
There is no online learning, gradient, optimizer, teacher, or action-list
lookup in the live runtime.

The current event's teacher action-list length is \(K\).  The neural student
learns whether to issue, the positive count \(K\), and one signed delta/target
address per slot.  \(K\) is not history length, training rows, hidden size,
model capacity, or a fixed prefetch degree.

\section{Fixed controls}
The trace is 602.gcc\_s-734B; seed is 7; epochs are 12; TBPTT length is 256;
and all optimizer, learning-rate, encoder, PC-keyed state, hurdle, count,
free-running decoder, teacher, class-balance, held-out stream, replay,
ChampSim, window, and metric definitions remain fixed.  Only retired training
instructions and the two predeclared curves h8/h16 vary.

h8 contains 1,908 trainable parameters (7,632 float32 bytes); h16 contains
5,220 (20,880 bytes).  Per observed PC, recurrent state is \(8H\) bytes.

\section{Measurement boundary}
Primary parity mode uses 25M warmup plus 25M measured instructions. Warmup
callbacks neither advance neural state nor issue neural requests. At the first
measured callback the PC-state map is explicitly empty. Optional realistic
state warmup is separately named and never mixed into a parity row.
